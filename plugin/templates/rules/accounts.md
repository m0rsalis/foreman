- **Agents run on the agents' account, a second subscription.** `{{TOOLS}}/claude-agents.sh` is `claude` on that account's config folder (`~/.claude-agents`): use it for every command on an agent (start, list, logs, stop, rm, resume) and for `{{HEARTBEAT}}` too, so the lead's usage limit cannot stop them. The lead runs on whatever account its session is signed in to; nothing else changes if that moves. `{{TOOLS}}/lead_status.py` lists both accounts' sessions with the command for each. When the agents' account hits its limit its agents wait for its reset; moving one to the main account needs {{OWNER}}'s OK. Setup, once: `{{TOOLS}}/claude-agents.sh --setup`, then sign in on that account.
